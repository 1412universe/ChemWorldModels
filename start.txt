# 推送：强制走 GitHub SSH 的 443 端口（勿用默认 22）
# 教训：git@github.com 默认连 22，常报
#   ssh: connect to host github.com port 22: Undefined error: 0
#   fatal: Could not read from remote repository.
# 那是网络/防火墙拦了 22，本地 commit 其实已成功；修好推送方式后直接再 push 即可。
GIT_SSH_COMMAND='ssh -o Hostname=ssh.github.com -p 443 -o User=git' git push origin main
