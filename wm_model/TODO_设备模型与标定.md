# 待办 A：按设备做「模型 + 标定」

> 当前已走方案 B（预演结果的 3D 叙事/虚跑）。本文件记录方案 A：要更准时再做。

## 目标

每台设备在自己的功能边界里把可观测量预测准，再在闭环里合成；不要一个黑盒直接吐产率。3D 只可视化 A 的输出，不承担精度。

## 设备拆分

| 设备 | 输入 → 输出 | 标定真值 |
|------|-------------|----------|
| 气路 | 设定流量/阀位 → 实际流量、配比、切换延迟 | 流量计 vs 设定 |
| 光照 | 功率/波长档 → 面照度或等效光子通量 | 探头 / 标准灯（增益与非线性） |
| 反应器 | 催化剂、光、气、温、时 → 转化/选择性 | 历史批 + 受控实验；标清适用域 |
| GC/分析 | 保留时间、峰面积 → 浓度 | 标样响应因子与漂移校正 |
| 调度/AL | 只消费各层均值、不确定度、约束 | 不偷偷改物理量 |

## 标定原则

1. 先定每台设备的「输入–输出」与可测真值（有传感器闭环标；没有则标样/金标准间歇校）。
2. 分工况网格或主动采样，覆盖常用区，少打无效点。
3. 存「设备模型版本 + 标定日期 + 适用域」；漂移超阈重标，不混进总模型硬调。
4. 合成顺序：气路/光照 forward → 反应器 → GC 换算；安全与硬件限位在设备层卡死。
5. 评测先按设备 KPI（流量误差、照度误差、产率 MAE/校准曲线），再评端到端。

## 产出物

每设备可版本化的 `predict + calibrate + domain`；总览预演读合成链路。

## 建议落地顺序

1. 气路偏差标定（设定 vs 实测）
2. 光照照度/功率曲线
3. 反应器局部模型（经验表 / kNN / GP）+ 适用域
4. GC 响应因子与漂移
5. 端到端合成接入预演 API，3D 仍只做叙事
