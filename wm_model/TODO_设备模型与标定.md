## 1. 分层可校准世界模型（怎么做）

**原则**：每层只预测本层可观测量 + 不确定度 + 适用域；上层读下层输出，**禁止**一个黑盒直接吐产率后反改物理量。

```
设定(流量/功率/质量/负载)
  → [气路] 实际流量、配比、σ
  → [光照] 面照度/相对光功率、σ
  → [反应器] 动力学先验(wm_kinetics/DFT) + 残差 surrogate → ŷ, ŝ, σ
  → [GC] 峰面积→浓度/产率换算
  → [AL/BO] 只消费 (μ, σ, 约束)，推荐下一组实验
```

| 层 | 输入 → 输出 | 标定真值 | 模型形态（建议） |
|----|-------------|----------|------------------|
| 气路 | 设定流量 → 实测流量/配比 | MFC/流量计 | 线性/分段增益 + 延迟；版本化 |
| 光照 | 功率% → 照度/相对光功率 | 探头 | 非线性曲线；与历史 `lpd` 对齐 |
| 反应器 | 气+光+负载+质量 → y, sel | 主表+新实验 | **先验动力学 + 残差 GP/XGB**；标 DoA |
| GC | 峰面积 → 浓度/产率 | 标样 | 响应因子；漂移超阈重标 |
| 调度 | (μ,σ,域) → 下一条件 | 闭环命中率 | 多目标 BO（硬 sel 门槛） |

**反应器层（核心）推荐拆两段：**
1. **先验**：`wm_kinetics.worldmodel_predict`（+ 可选 DFT 描述符）给出趋势与粗量级  
2. **残差**：`log y_exp − log y_prior`、`sel_exp − sel_prior` 用 GP/XGB 拟合条件特征；预测时 `y = prior × 10^ε`  
3. **域**：训练凸包 / 马氏距离外降低置信或拒推  

评测：先各层 KPI，再端到端；3D/预演只可视化合成结果，不扛精度。

- [ ] 留出未见负载/流量区做 hold-out；消融：无动力学 / 无 AL / 纯表模型
